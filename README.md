AZUS is an AI system with a memory that keeps what mattered, a record that can be checked afterward, and a deterministic connection to real machines. It is designed by one architect and built by a professional programming team at Westfield Innovations.

## What we build

**Pressure-Driven Memory (PDM)** — persistent, resonance-based memory for AI programs. It keeps what mattered, validates what it kept against outcomes, and lets the rest fall silent instead of hauling every token through every call. Memory is not storage; memory is compressed meaning, and retrieval is commanded by pressure, not allocated by polling.

```
pip install pdm-memory
```

**AZUS** — the system built on that memory: it remembers across interactions, reviews what it holds, and compares what it expected with what actually happened. [azus.ai](https://azus.ai)

**AZUS Field** — field operations for working crews: hours, receipts, work records, and hand-offs, with a record that can be verified after the fact. [field.azus.ai](https://field.azus.ai)

**AZUS to PLC** — a model may propose a move; a deterministic layer posts it, inside the PLC's own permissives and interlocks; and a witness that touches nothing records the exchange. Industrial AI that reaches a machine without being allowed to run it.

## How we build

- **Memory is not storage.** What is kept is meaning, weighted by what it mattered, and validated against what happened next.
- **The record is never edited.** The current state is drawn from the record, never written over it, so anything can be checked afterward.
- **A model proposes; deterministic controls post.** Authority, conditions, and limits live at the output, where the machine is, not inside the model.
- **Boundaries are defined before anything moves.** A change declares what it may touch, and a witness outside the change judges it.

## Free instruments

Two reading tools we publish for anyone to use, share, and adapt, with their credit blocks attached. The **Noun Probe** pins every word in a document to one job and exposes words doing two. The **Curve Tool** reads any interaction as where it loses, where it holds, where it lags, and how it lands.
